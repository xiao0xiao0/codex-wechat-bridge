# Codex 微信桥接 v0.9.30

v0.9.30 是一次以“长期稳定在线与安全恢复”为重点的稳定版更新。它完整包含 v0.9.23—v0.9.29 的长文本分段、独立附件队列、积压清空、时区修复和微信直连能力，并重点解决微信轮询游标损坏后监控停滞或历史命令重放的风险。

这是面向 Windows Codex 桌面版的社区桥接插件，不是 OpenAI 或腾讯官方产品，也不需要安装或运行 OpenClaw。

## 本版最重要的变化

### 微信同步游标自动自愈

桥接现在会在每次轮询前严格验证持久化的 `sync.json`，覆盖以下异常：

- 文件缺失或为空；
- 文件包含 NUL 字节；
- JSON 无法解析；
- 缺少 `get_updates_buf` 字段；
- 游标字段为空。

发现损坏后，原文件会被隔离备份，桥接再通过空基线向服务器获取最新非空游标。恢复请求返回的所有消息都会被明确丢弃，不进入 inbox、不执行，也不补发，从而避免长期断开后把历史微信命令当作新命令重放。

### 网络故障不会破坏健康游标

DNS、TLS、超时和服务器异常响应不会覆盖现有健康游标。只有服务器返回非空新游标时才会原子提交；恢复原因、备份位置、丢弃数量和非敏感游标指纹会记录在本地 `sync-recovery.json` 中。

监控失败采用 3、6、12、24、30 秒退避，相同错误五分钟内不重复刷日志；连接恢复后只记录一条恢复信息。微信发送 `/诊断` 可以看到“微信游标：正常”或“等待自动恢复”。

## 从 v0.9.22 到 v0.9.30 的累计改进

- **长结果分段（0.9.23）**：按段落或句子拆分长回复，每段保留完整任务抬头，引用任意一段都能继续原任务。
- **独立附件队列（0.9.24）**：每个附件独立重试，一个失败文件不会阻塞其他任务；自动附件上限提高到 10 个。
- **Markdown 排除（0.9.25）**：`.md`、源码、配置和日志不再自动作为微信附件发送。
- **积压清空（0.9.26）**：无需引用即可发送 `/清空`，归档尚未发送的通知和附件，并从当前时刻继续监控。
- **UTC 水位修复（0.9.27）**：修复无时区标记的 Codex 时间在 UTC+8 系统上的比较偏差。
- **微信传输适配（0.9.28—0.9.29）**：默认直连腾讯 iLink/CDN，避免本机系统代理造成 TLS 异常；仍可选择 `system` 或 `auto` 模式。
- **游标安全自愈（0.9.30）**：损坏状态自动恢复，历史命令不重放，健康游标不被异常响应覆盖。

完整技术记录见 [CHANGELOG](https://github.com/xiao0xiao0/codex-wechat-bridge/blob/main/plugins/codex-wechat-bridge/CHANGELOG.md)。

## 主要使用方式

无需引用：

- `/在线`：检查桥接在线状态；
- `/桥接状态`：查看投递和执行队列；
- `/状态`、`/状态 最近`、`/状态 完整`：查看执行状态和进展；
- `/诊断`：检查监控、计划任务、游标和积压；
- `/清空`：归档未发送积压，从当前时刻继续；
- `/新建 任务内容`：新建独立 Codex 对话。

需要引用任务通知：

- 直接回复文字：继续对应的 Codex 对话；
- `/分支 任务内容`：复制完整对话历史并创建新的对话分支；
- `/附件`、`/附件 重试`、`/附件 <序号>`、`/附件 全部`：查看、重试或补充发送该任务附件。

## 安装与升级

首次安装：

```powershell
codex plugin marketplace add xiao0xiao0/codex-wechat-bridge
codex plugin add codex-wechat-bridge@codex-wechat-bridge
```

也可以下载或克隆仓库后，在仓库根目录运行：

```powershell
pwsh -NoProfile -File .\install.ps1 -Configure -StartNow -EnableRelay
```

从旧版本升级：

```powershell
codex plugin marketplace upgrade codex-wechat-bridge
codex plugin add codex-wechat-bridge@codex-wechat-bridge
```

随后从最新插件缓存目录重新运行 `Install-WeChatBridgeService.ps1 -StartNow`。微信登录信息和本地任务状态默认保留。

完整步骤见 [中文安装教程](https://github.com/xiao0xiao0/codex-wechat-bridge/blob/main/docs/%E5%AE%89%E8%A3%85%E6%95%99%E7%A8%8B.md)。

## 安全与隐私边界

- 微信凭据使用当前 Windows 用户的 DPAPI 加密；仓库和安装包不包含任何使用者凭据。
- 只有扫码绑定的微信用户会被接受，双向执行必须由使用者明确开启。
- 普通未引用消息不执行；继续任务和 `/分支` 必须引用桥接生成的任务通知。
- 游标恢复返回的历史消息不会写入执行 inbox。
- 附件上传到微信 CDN，自动发送默认关闭，必须明确启用。
- 桥接不会自动批准 Codex 权限或代替用户完成交互确认。
- 本项目依赖腾讯微信 iLink/ClawBot 网络接口，上游变化可能影响兼容性。

## 已知限制

- 微信续接现有桌面对话依赖 Windows UI 自动化；Windows 锁屏、Codex 窗口不可操作或任务标题无法核对时，本次内容不会提交。
- 这是 Windows 专用版本，尚未提供 macOS 或 Linux 安装方案。
- 首次扫码或主动发送上下文过期时，需要给 ClawBot 发送一条消息刷新会话上下文。
- 使用必须经过系统代理的网络时，需要手动把 `wechat_http_proxy_mode` 改为 `system` 或 `auto`。
