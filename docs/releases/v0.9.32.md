# v0.9.32 稳定版：任务改名与重启后的微信续接修复

本版包含 0.9.31 和 0.9.32 的全部修复，并保留此前的通知、引用续接、新建、分支、状态进展、附件队列、清空与游标自愈功能。

## 任务改名后仍可引用旧通知

例如，任务由“项目讨论”改为“方案设计”后，微信里仍可能保留旧名通知。桥接现在根据同一个任务 ID 取得当前名称，在收到引用回复、排队等待结束以及桌面提交前重新核对名称。历史通知仍能用于确认原任务，不会因为其他任务同名而切换目标。

名称目录尚未同步时仍可能暂时拒绝提交；桌面标题与输入框检查保持生效。失败内容不会自动重发，请确认后重新引用通知发送。

## 重启或上下文压缩后保持正确任务身份

0.9.31 修复了复合记录文件名中流 ID 被误认为任务 ID 的问题。完成监控和 `/状态` 现在读取会话元数据，选择属于目标任务的最新记录；真实分支仍保留自己的身份。

旧通知中的流 ID 只有在能够核实归属时才会恢复到原任务。监控修正身份时保留读取位置，避免重新发送历史完成通知。身份冲突会拒绝执行。

## 安装和升级

新用户请阅读 [中文安装教程](https://github.com/xiao0xiao0/codex-wechat-bridge/blob/main/docs/安装教程.md)。需要 Windows、PowerShell 7、Codex 桌面应用以及微信机器人入口。

已有用户按安装教程的更新步骤升级 marketplace、重新安装插件，并从最新缓存目录重启桥接服务。微信登录及本地队列继续保留。完成后使用 `/诊断` 核实运行版本为 0.9.32。

## 验证与边界

发布检查覆盖插件结构、PowerShell 语法、公开包敏感信息、任务身份识别、旧通知改名续接、等待期间再次改名、单次提交、防重放及游标恢复。离线测试不会向真实微信发送消息，也不会提交真实 Codex 任务。

桌面续接仍依赖 Windows 已解锁、Codex 窗口可操作及任务目录可用。离线测试通过不代表所有桌面和网络状态下都能成功。
