# Codex 微信桥接 v0.9.22

不用一直守在电脑旁，也能知道 Codex 做完了没有；看到微信通知后，还可以引用那条通知，把下一步要求准确送回原来的 Codex 对话。

这是一个面向 Windows Codex 桌面版的社区桥接插件。它把 Codex 的任务完成、暂停和失败状态发送到微信 ClawBot，并提供受控的双向续接、新建对话和对话分支能力。它不需要安装或运行 OpenClaw，也不是 OpenAI 或腾讯官方产品。

## 适合哪些场景

- Codex 正在长时间执行任务，你希望离开电脑后通过微信获知结果。
- 多个 Codex 对话同时运行，需要看清是哪个任务完成，并准确回复到对应对话。
- 一个任务结束数小时后才看到通知，仍希望从微信继续原任务。
- 想从微信新建独立 Codex 对话，或复制某个已有对话的完整历史后换一个思路继续。
- 希望完成结果中的附件也能发到微信，同时保留明确的隐私开关。

## 主要功能

### 1. Codex 状态主动通知

任务完成、暂停或失败时，微信会收到中文通知，例如：

```text
【已完成】讨论算电协同需求表思路
结果摘要
```

通知包含对话名称而不是难以辨认的内部 ID。若微信主动发送上下文暂时失效，通知会留在本地队列；给 ClawBot 发送任意消息后，桥接会刷新上下文并继续投递。

### 2. 引用通知，准确续接原对话

长按需要继续的任务通知，选择“引用”，再输入下一步要求。引用关系用于确定目标任务，因此即使多个对话同时完成，也不会用“最近完成时间”猜测目标。普通未引用消息不会被当作任务执行。

### 3. 微信新建对话和对话分支

- `/新建 任务内容`：无需引用，创建桌面可见的独立 Codex 对话；不复制旧历史，也不新建项目目录。
- `/分支 任务内容`：必须引用来源任务通知，复制该对话已经保存的完整历史，再创建新的桌面对话继续执行。

这里的“分支”是 Codex 对话分支，不是 Git branch，也不是 Git worktree。

### 4. 查看任务和阶段性进展

- `/状态`：只看当前真正执行中的任务和最新用户可见进展。
- `/状态 最近`：查看最近任务的状态和名称。
- `/状态 完整`：查看最近任务及结果摘要。
- `/诊断`：检查后台服务、Codex、PowerShell、队列和日志状态。

### 5. 可选附件发送

附件自动发送默认关闭。使用者明确开启后，桥接可发送最终回复中引用的现有本地输出文件；文本和附件分别记录投递进度，附件失败不会重复发送完成文字。

## v0.9.22 重点改进

- `/状态` 以 Codex 桌面任务目录和最新生命周期事件为准，只显示真正执行中的任务，减少历史记录和假“执行中”。
- 原生对话分支不再把复制来的旧完成事件当成新通知发送，避免微信突然涌出历史消息。
- 当分支来源记录暂时不可用时采用“失败关闭”策略，只允许桥接明确记录的新一轮任务通过。
- 缺少分支来源时只记录一次可操作警告，避免日志反复刷屏，同时不影响后续正常增量通知。

完整技术变更见 [CHANGELOG](https://github.com/xiao0xiao0/codex-wechat-bridge/blob/main/plugins/codex-wechat-bridge/CHANGELOG.md)。

## 安装要求

- Windows 10 或 Windows 11
- 已登录的 Codex 桌面应用
- PowerShell 7（`pwsh`）
- 微信中的 ClawBot/微信机器人入口
- 安装、扫码和微信续接期间 Windows 保持解锁，Codex 窗口可操作

## 快速安装

下载或克隆仓库后，在仓库根目录使用 PowerShell 7 运行：

```powershell
pwsh -NoProfile -File .\install.ps1 -Configure -StartNow -EnableRelay
```

该命令会添加或更新 marketplace、安装插件、发起微信扫码绑定、启动后台服务，并明确开启微信到 Codex 的执行权限。只想先接收通知时，可以省略 `-EnableRelay`。

完整步骤、手动安装、升级、卸载和排障见 [中文安装教程](https://github.com/xiao0xiao0/codex-wechat-bridge/blob/main/docs/%E5%AE%89%E8%A3%85%E6%95%99%E7%A8%8B.md)。

## 安全和隐私边界

- 微信凭据使用 Windows DPAPI 加密，只能由当前 Windows 用户解密。
- 运行状态默认保存在 `%LOCALAPPDATA%\CodexWeChatBridge`，不会写入公开仓库。
- 只有扫码绑定的微信用户会被接受；双向执行必须由使用者明确开启。
- 继续任务和 `/分支` 必须引用桥接生成的任务通知；校验失败时不提交内容。
- 桥接不会自动同意 Codex 的权限审批或代替用户处理交互式确认。
- 附件上传到微信 CDN，默认关闭，必须明确启用。
- 本项目调用腾讯微信 iLink/ClawBot 网络接口，上游变化可能影响可用性。

## 已知限制

- 微信续接现有桌面对话依赖 Windows UI 自动化；锁屏、Codex 窗口不可操作或无法核对目标标题时，本次内容不会提交。
- 微信主动发送上下文可能过期。通知不会因此丢弃，但需要使用者给 ClawBot 发送一条消息以刷新上下文。
- 这是 Windows 专用初版，尚未提供 macOS 或 Linux 安装方案。
- 腾讯微信接口或 Codex 桌面内部界面变化后，可能需要同步升级桥接插件。

## 从旧版升级

```powershell
codex plugin marketplace upgrade codex-wechat-bridge
codex plugin add codex-wechat-bridge@codex-wechat-bridge
```

重新定位最新插件缓存目录后，再运行 `Install-WeChatBridgeService.ps1 -StartNow`。微信登录信息和本地任务状态默认保留。
