# Codex 微信桥接安装教程

## 1. 安装前准备

请先安装并登录：

1. Windows 10 或 Windows 11。
2. Codex 桌面应用。
3. PowerShell 7。打开 PowerShell 7 后，运行 `pwsh --version` 应能看到版本号。
4. 微信中的 ClawBot/微信机器人入口。

安装和扫码绑定必须由使用者本人完成。仓库不包含作者或其他用户的登录凭据。

## 2. 添加仓库 marketplace

如果已经下载或克隆仓库，可以直接运行一体化安装：

```powershell
pwsh -NoProfile -File .\install.ps1 -Configure -StartNow -EnableRelay
```

它会依次添加/更新 marketplace、安装插件、扫码绑定、启动后台服务，并在最后明确开启微信执行权限。如果只希望先接收通知，可省略 `-EnableRelay`。

下面是等价的手动步骤。

在 PowerShell 7 中运行：

```powershell
codex plugin marketplace add xiao0xiao0/codex-wechat-bridge
codex plugin add codex-wechat-bridge@codex-wechat-bridge
```

第一条命令把 GitHub 仓库登记为 Codex marketplace；第二条命令安装其中的插件。官方 Codex 插件机制支持使用 Git 仓库作为 marketplace 源。

如果同名 marketplace 已存在，先查看：

```powershell
codex plugin marketplace list
```

## 3. 定位已安装插件

```powershell
$plugin = Get-ChildItem "$env:USERPROFILE\.codex\plugins\cache\codex-wechat-bridge\codex-wechat-bridge" -Directory |
  Sort-Object Name -Descending |
  Select-Object -First 1

$plugin.FullName
```

后面的命令都从这个已安装目录运行，避免下载 ZIP 后使用错误版本。

## 4. 扫码绑定微信

```powershell
pwsh -NoProfile -File "$($plugin.FullName)\scripts\Connect-WeChatBridge.ps1"
```

脚本会打开二维码。用需要接收通知的微信账号扫码确认。绑定完成后，在微信中给 ClawBot 发送任意一条普通消息，让桥接取得新的会话上下文。

## 5. 安装后台服务

```powershell
pwsh -NoProfile -File "$($plugin.FullName)\scripts\Install-WeChatBridgeService.ps1" -StartNow
```

该脚本注册当前 Windows 用户的计划任务，并立即启动主监控和完成监控。无需管理员权限；Windows 登录后会自动启动。

## 6. 开启微信执行权限

默认只建立队列，不执行微信发来的任务。确认是自己的微信账号后，运行：

```powershell
pwsh -NoProfile -File "$($plugin.FullName)\scripts\Enable-WeChatCodexRelay.ps1"
```

如需临时关闭微信执行、但保留通知：

```powershell
pwsh -NoProfile -File "$($plugin.FullName)\scripts\Disable-WeChatCodexRelay.ps1"
```

## 7. 检查安装

```powershell
pwsh -NoProfile -File "$($plugin.FullName)\scripts\Get-WeChatBridgeDoctor.ps1"
```

正常状态应包含：

- 主监控：正常
- 完成监控：正常
- 计划任务：Running
- Codex：可用
- PowerShell 7：可用

也可以发送一条文字测试通知：

```powershell
pwsh -NoProfile -File "$($plugin.FullName)\scripts\Send-WeChatBridgeTest.ps1"
```

## 8. 日常使用

完成通知格式：

```text
【已完成】对话名称
结果摘要
```

要继续某个任务，长按该通知，选择“引用”，然后输入任务内容。为了避免多个任务同时结束造成歧义，续接和 `/分支` 必须引用对应通知。

新建对话无需引用：

```text
/新建 整理这份需求
```

从某个任务复制完整历史并继续，需要引用该任务通知：

```text
/分支 换一个思路继续分析
```

长结果会按段落或句子分成多条微信消息，每一段都保留完整任务抬头，因此引用任意一段都能准确续接。

需要查看或重试某个已完成任务的附件时，引用该任务通知后发送：

```text
/附件
/附件 重试
/附件 2
/附件 全部
```

长期未使用、不希望补发旧积压时，可以直接发送 `/清空`。它会把尚未发送的文字和附件移入本地可恢复归档，并从当前时刻继续监控；不会停止 Codex 任务或删除本地成果文件。

## 9. 更新

```powershell
codex plugin marketplace upgrade codex-wechat-bridge
codex plugin add codex-wechat-bridge@codex-wechat-bridge

$plugin = Get-ChildItem "$env:USERPROFILE\.codex\plugins\cache\codex-wechat-bridge\codex-wechat-bridge" -Directory |
  Sort-Object Name -Descending |
  Select-Object -First 1

pwsh -NoProfile -File "$($plugin.FullName)\scripts\Install-WeChatBridgeService.ps1" -StartNow
```

微信登录信息和本地任务状态位于 `%LOCALAPPDATA%\CodexWeChatBridge`，更新插件不会主动删除它们。

## 10. 卸载

停止并移除后台计划任务：

```powershell
pwsh -NoProfile -File "$($plugin.FullName)\scripts\Uninstall-WeChatBridgeService.ps1"
```

然后从 Codex 中移除插件或 marketplace。卸载服务脚本默认保留本地凭据、队列和日志，防止误删；如需清除本地状态，请在确认不再需要后手动删除 `%LOCALAPPDATA%\CodexWeChatBridge`。

## 11. 常见问题

### 微信收到“等待执行”，但没有继续

先发送 `/诊断`。续接现有桌面任务时，需要 Windows 已解锁、Codex 窗口可操作，而且被引用通知必须属于目标任务。

### 完成通知过一段时间才看见

如果微信主动发送上下文过期，桥接会保存最新通知。给 ClawBot 发送任意消息后会自动补发；通知路由不依赖“几分钟内回复”。

### 同时完成多个任务怎么回复

引用希望继续的那一条任务通知。插件不使用“最近完成时间”猜目标。

### 分支和 Git 分支有什么区别

这里的 `/分支` 是 Codex 对话分支：复制已经保存的对话历史，创建新的 Codex 任务。它不会创建 Git branch 或 worktree。

### `/诊断` 显示“微信游标：等待自动恢复”

桥接会在下一次轮询前隔离损坏的 `sync.json`，通过空基线取得服务器最新游标，并丢弃恢复响应中的历史消息，避免旧命令重放。DNS、TLS、超时或异常响应不会覆盖原有健康游标。网络恢复后再次发送 `/诊断`，预期显示“微信游标：正常”。

### 本机代理导致微信 TLS 失败

0.9.30 默认让腾讯 iLink 和 CDN 直连，避免本机系统代理中断 TLS。确实必须走代理时，可在 `%LOCALAPPDATA%\CodexWeChatBridge\config.json` 中把 `wechat_http_proxy_mode` 设置为 `system`；`auto` 仅在系统解析到真实代理时使用代理。
